# やわらかい音と短い余韻

音程・発音時刻・元の線・音符の対応はそのままに、共通のWeb Audio音源を調整した。追加の設定操作やサンプルのダウンロードは不要。

## 響き

- 5音色それぞれに立ち上がり・初期減衰・持続・余韻を設定。上の倍音ほど先に消え、長い線は基音で支える。
- 高音域の音量と鋭い倍音を抑え、出力段のローパスで響きを整える。
- 17〜21msの遅れから始まる0.45秒の小さなステレオ残響。固定シードからローカル生成し、再生ごとに響きが変わらない。
- 停止時は現在の振幅から25msでゼロへ。まだ鳴っていない音は直ちにキャンセル。庭の音声経路も消音完了まで保持してから解放。
- スタジオ、作品帳、庭、WAV、共有動画は同じ音源と出力処理を利用。動画用の既存の末尾1.4秒に余韻が収まる。

## 2026-09-21の検証

- Vitest 112件、本番ビルド成功。
- 実ブラウザのOfflineAudioContextで5音色×ハート・猫・波を生成。密集例を含め、有限の音声信号・非無音・ピーク1未満・末尾の消音を確認。
- ハートのピアノ：変更前ピーク0.179 / RMS0.0249、変更後0.144 / RMS0.0208。音量だけを上げる調整はしていない。
- 停止境界の最大隣接サンプル差は、検証用ピアノで0.0390から0.00489へ減少。停止後40msで発振器は無音。残響は別途自然減衰する。
- 6秒の持続音は4〜5秒地点でもRMS0.0224。予約した未来の音のキャンセル後は完全無音。
- 庭の掛け合い、途中参加、停止、12作品の密集も既存の実音声検証で確認。
- 音の好みと端末のスピーカーでの聴こえ方は数値だけでは評価できない。PCのChromiumで生成を確認し、実機の聴取調整は継続対象。
