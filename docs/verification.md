## ブラウザで確認したこと

- 猫の見本を表示し、スライダー変更前後で全ての元パスが同一。
- 実マウスドラッグで縦線を描き、複数ピッチの音符が同じ拍に配置される。
- 描画中にネイティブAudioContextが発音する。
- 再生中の音声時計がrunning、音源が動作し、再生ヘッドが表示される。
- STOP後にアクティブな発振器が0。自然終了後も音が残り続けない。
- 曲終了時に絵全体の控えめな発光が発生する。
- 消しゴム、Undo、Redo、ボタンにフォーカスが残った状態でのCtrl+Z。
- 作品名・描画・音色が再読み込み後に復元される。
- PNG / WAV / MIDI / JSONをSaveメニューからダウンロード、JSONを再読み込み。
- あそびかたダイアログの開閉。
- 390 × 844で横はみ出しなし。PLAYとスライダーが画面内、作品名編集可能。
- CDPによるタッチ入力で円を描画。タッチキャンセルで中断した線が残らない。
- 円の画面上の縦横比: モバイル0.99998、PC幅に変更後0.99995。元のパスは同一。
- 最終ブラウザログにエラー・警告なし。
