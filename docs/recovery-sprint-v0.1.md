## 4. 安全な統合計画

1. **`recovery/live-0921` をpushし、mainへのPRにする**（Draft）。公開中のコードをGitHubへ戻すのが最優先。受入条件：CI成功＋スマホ幅での主要導線。
2. **#56をその上へ**。衝突はなく、離脱時の保存という公開版の実バグを直す。CIワークフローも入る。
3. **#55はそのまま統合しない**。共有機能と役割が重なり、3ファイルで衝突する。ぷち音符を動画に描く描画部分だけを `src/share/painter.ts` へ移植し、PRは閉じる。
4. **#44・#48は閉じる候補**。HOMEとブランドは#54とローカルで実装済み。差分を一度確認してから閉じる。
5. **#40・#42・v0.9〜v0.10チェーンは凍結**。9/13基点で大きく乖離しているため、必要な部分を新しいmainへ小さく取り込み直す。
6. デプロイは「main→CI→ホスティング」の一本道にする。Netlify無料枠の件は、2025年以降の新しい無料プランがクレジット制で、本番デプロイ1回ごとにクレジットを消費する点が原因の可能性がある。サイトは約1.7MBなので、転送量より可能性が高い。ダッシュボードのUsageで確認する。代替はCloudflare Pages（静的配信の帯域無制限）。

## 6. 体験改善トップ5

1. **「できた！」に「庭に植える」を追加**：保存の直後に庭へ行ける。MDE（最小感動体験）の締めになる。
2. **共有動画にぷち音符を描く**：#55の描画部分を移植する。SNSで「絵が音符になる」が一目で伝わる。
3. **既定の筆は「虹」（1本ごとに色が巡る）**：以前の驚きを戻しつつ、色の選択も残す。
4. **#56の統合**：保存の取りこぼしは信頼を損なうため、楽しさより先に直す。
5. **スマホのGardenを庭中心に**：ヘッダーを圧縮し、植える・聴く操作を親指の届く位置へ。
