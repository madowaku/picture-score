# Garden v0.4 — PLAYGROUND 実装メモ

Issue #4 / `Picture Score v0.4 — PLAYGROUND: everything invites a touch` に対応。

## 触れるたびに返事する

- DRAWは既存のリアルタイム音階吸着・速度による発音長を使い、指を離して220ms後にそのストロークだけを短いフレーズで返す。
- 線の向き・滑らかさ・細かさから「縦のコード」「横のロングトーン」「なめらかな線」などの性格を小さく表示。正解ではなく、次の描き方を誘うヒントとして扱う。
- GARDENの作品はタップ、Enter、Spaceで試聴できる。再生中は共通クロックの次の四分音符へ、停止中は独立した短い返事へスナップする。
- 配置・回答・Spotlight・取り除きには短い合成音と、対応端末だけの小さな振動を使う。音声コンテキストが使えない場合も描画や配置は継続する。

## PLAYGROUNDの見え方

- PLAYを珊瑚色の主役ボタンにし、再生中は弱い呼吸で状態を示す。描画中の回答は紙の縁とステータス点で知らせる。
- リスナーは青い耳のオーブとして庭を歩き、ドラッグ中だけ短い軌跡を残す。距離の近い作品には小さなリング、発音中には作品自体の呼吸を表示する。
- 強い関係は選択時の近傍、または未選択時の上位3本だけを糸として表示。最初の強い関係では双方を次の境界で短く返し、900msで静かな表示へ戻す。
- Spotlightは4拍だけ選択作品を前に出し、周囲を少しだけ下げる。ミュートやスコア、XPなどのゲーム化は行わない。

## 検証

- `scripts/verify-playground.cjs`: 空のDRAW導線、線の回答、PLAY、Gardenの配置・タップ・Spotlight、390px再読込を確認。
- `npm test` / `npm run build` と既存のENSEMBLE、言語切替、GROWブラウザ検証を回帰実行。

画面幅によるブラウザ確認は行っているが、実機のiOS/Androidでの音声復帰・振動と、子供・大人による長時間の主観的な試遊は未実施。
