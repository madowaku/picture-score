# Picture Score v0.5 — WONDER

Issue #5 / [仕様](picture-score-v05-wonder.md) の6つの法則を実装。

## 描く・重ねる・聴く

- 閉じた形はその形の演奏時間を二分し、輪郭を一度だけリピート。端点がつながった最大12本の連結輪郭も対象。点・小さな輪・単なる往復のなぞり描きは除外。
- なぞり描きは双方向の輪郭一致率78%以上。重複発音をまとめ、2回目は静かなオクターブ、3回目以降はもう一つのオクターブ色を加える。追加音は48音、追加時の同時発音は8音まで。
- 交差はX方向に近いものを統合し、1小節2回、全体8回までの短いアクセント。端点の接触は交差にしない。
- 左右対称は反転した輪郭の一致率86%以上で判定。右半分の音域・アーティキュレーションを少し変える。1本で描いたハート、別々に描いた左右の輪郭に対応。
- 33点の弧長サンプルと不変ストロークのキャッシュで判定。意味認識、乱数による発動、元の線の改変は行わない。

## 庭の並べ方

- 3作品以上を横または縦に並べると、最初の12拍を空間順に分担。横は左から右、縦は上から下。
- 適度な大きさの三角形は3作品が4拍ずつ返事し、16拍の共通フレーズ境界で先頭を交代。細すぎる、近すぎる、遠すぎる三角形は対象外。
- 配置関係は220msの安定を待つ。整列のズレや三角形の辺比に許容帯を設け、強さを連続的に変える。
- 4小節目は既存ENSEMBLEへ戻る。許容帯の縁では元のENSEMBLEと空間演奏を混ぜる。
- GardenTransportの既存free / ensembleバスと共通AudioContextを使用。移動ではstart/stopを呼ばない。
- 空間会話の参加者は役割別ミックス上限によって3人目だけ消えないようにし、全体のゲイン正規化・声数制限は保つ。

## 色とヒント

色鉛筆のような6色の線・音符、黄色のDRAW、葉色のGARDEN、ピンクのPLAY。線の色はPNGにも反映する。発見時は線の短い発光、閉じた線の弾性、庭の点線と移動する光で反応する。動きを減らす設定ではアニメーションを止め、機能と静的な反応を残す。

ヒントは実験を誘う日英6文。描画・消去・ドラッグ中は消え、表示は約6.5秒、次の提案までは約24秒空ける。ブラウザ内の独立したwonder:v1メモリは未経験の提案を優先するためだけに使う。発見数・バッジ・解除通知は表示しない。

## データと書き出し

Stroke / Score / Music IRとProject version 1、Garden version 1、GROWの保存形式は維持。WONDERは独立した検出結果から演奏用MusicIRを派生させる。DRAWのライブ演奏・WAV・MIDIは同じ派生演奏を使用する。Gardenの独立声部も同じDRAW法則を参照するが、保存されたmusicIRや役割分類は変更しない。
