# Garden v0.3 — GROW 実装メモ

Issue #3 / docs/garden-v03-grow.md に対応。

## 聴いた時間だけが残る

- 既存の音声時計を四分の一拍ごとに読み取り、現在の発音区間と実効レイヤーゲイン・距離ゲインを確認。0.015以下、非表示、音声停止、欠落した時計区間には加算しない。
- STOP、DRAWへの移動、非表示で演奏を停止。経過した壁時計時間やオフライン時間から補完しない。
- オブジェクトは4 / 16 / 32拍、道は8 / 24 / 48共有拍で姿が変化し、64拍で上限。
- v0.2の強い掛け合いは同時に鳴らないため、共有拍は16拍のフレーズ内に実際に聞こえた双方の拍の小さい方。関係強度を掛け、双方の距離ゲインが有効な関係だけを記録する。未完の証拠は停止・分離・フレーズ境界で捨てる。厳密な同時発音の積ではなく、応答を含む共有体験として解釈した。
- 音声波形を解析する聴覚測定ではなく、既存スケジューラの発音区間を使った境界サンプリング。短い音の知覚時間との完全一致は保証しない。

## 保存と描画

- 成長は独立した picture-score:growth:v1 キー。元のProject / Stroke / Score / Music IRは変更しない。
- 古い庭は成長ゼロから開始。成長データが壊れている場合は元データを上書きせず、作品を維持したまま警告する。
- 移動は現在の作品位置へ追随。取り除いた作品と関連する道の記録は削除。
- 安定したIDから決定論的に描画。5役割ごとに葉・ロゼット・草・点・星。最大12群、各8要素、道は24本、道の装飾は2要素まで。
- SVG背景はポインターを受け取らない。成長時だけ550msのフェード、動きを減らす設定では静止。報酬音、スコア、モーダルなし。
- 発見文は日本語・英語対応。一度表示した種類は保存する。

## 初回導線

キャンバス上に「線を描く → PLAYで聴く → 庭に置く」の短い案内を常設し、描画中にレイアウトが動かないようにした。空の庭には描画へ戻る直接ボタンを追加。既存の線画・紙のデザインに合わせ、生成ビットマップは不要と判断。

## 検証

- npm test / npm run build
- scripts/verify-grow.cjs: 実再生の初芽と共有道、停止、再読込、分離、削除、破損データ保護。
- scripts/verify-grow-ui.cjs: 日英初回導線、390px幅、決定論的再描画、12作品/24道/96要素上限、成長後の移動、reduced motion設定。
- scripts/verify-ensemble-audio.cjs: 実Web Audioの掛け合い、途中参加、密集音量。
- scripts/verify-language.cjs: 日英切替、演奏・作品維持、デスクトップとスマホ幅。
- gardenGrowthObserver.test.ts: 非表示・小さい実効ゲイン・中断時計・AudioContext停止を再現。

実機iOS/Androidでの音声復帰と、子供・大人による5〜10分の主観的な試遊は未実施。スマホ確認はブラウザの画面幅によるもの。
