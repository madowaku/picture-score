# 最初の30秒を守る

## 優先順位

1. 描いた線を変えない。
2. 初めて触って音が出るまでを短くする。
3. 絵の空間と音の関係を裏切らない。
4. 表示する音符と演奏する音を分離し、線の表情からフレーズを選ぶ。
5. 設定を増やす前に、もう一度描きたくなるか確かめる。

## 今回取り入れたアイデア

### 空白は入口、見本は任意

最初は白いキャンバス。文章説明を必須にせず、薄いガイドと短い誘いだけを見せる。描き出せない人にはHeart / Wave / Cat。見本はユーザーが選んだときだけ入り、自作を置き換えてもUndoで復元できる。

### 伴奏が余白を勝手に埋めない

絵のある小節から和音を選ぶ。無描画の小節には新たな伴奏イベントを置かない。余韻は自然に残す。Drawing Layerの音量を主とし、伴奏は独立して切れる。

### 作品はまず持ち帰れる

サインアップなし。自動保存、再編集できるJSON、画像PNG、音声WAV、Drawing / Supportを分けたMIDIを用意。SNS動画は魅力的だが、録画のブラウザ互換性と音声同期を別途検証してから実装する。

### 失敗を軽くする

線単位の消しゴムと40段階のUndo/Redo。新しいキャンバスや見本への変更もUndo可能。元の絵は音楽的補正で書き換えない。

## v0.2のMusic Magnet

標準値は50%。表示は一定密度を保ち、YをCペンタトニックへ、Xを1/4拍グリッドへ小さく吸着させる。演奏用には同音の連続をまとめ、線の折り返しを優先してフレーズを間引く。右ほど間引き量と音の持続が増し、縦線のコードも声数を絞る。伴奏ONなら強さに比例して加わる（左端は無伴奏）。元の線も表示音符の数も減らさない。

UIに表示音符数と演奏音数を並べ、解釈の変化を見せる。演奏とWAV/MIDIは同じデータを使い、点灯も実際の音に追従する。詳細と実測値は [make-it-sing.md](make-it-sing.md)。音楽としての楽しさは、特に高密度の文字や絵、スマホ実機での聴取評価を続ける。

## 次のユーザー観察

- 説明なしで描画を始められるか。
- 左から右への再生と、縦線の和音に自然に気づくか。
- 見本なしの自分の絵でも、再生して楽しいか。
- スライダーの3位置を音で区別できるか。形は認識できるか。
- 伴奏ON/OFFで「自分が鳴らした」感覚が弱まらないか。
- 次の一枚を自発的に描くか。誰かに見せたいか。

水平線の同音をつなぐ「線の息継ぎ」はv0.2で実装した。次は新しい操作を増やさず、指を置く→線が付いてくる→離す→音符が吸着する感触を実機で確認する。

## AIを接続する際の境界

YuE2公式リポジトリの段階的パイプラインとABC入力を調査済み（2026-09-12）。現段階では接続しない。将来はMusic IRのSupport Layerを受け渡し、元のStroke IRとDrawing Layerを固定したまま伴奏を差し替える。全曲音声の再生成は厳密なタイミング保持を保証しないため、Drawing Layerの直接置換に使わない。
